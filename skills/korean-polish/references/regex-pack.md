# 정규식 탐지 팩 (recall-first)

Detection only. **재현율 우선으로 넓게 잡고 확정은 사람/LLM 판단.** Regex flags a
*candidate*; it never edits. Over-correction is the main risk, so every hit goes
through suggest→confirm. Protected spans (`$...$`, numbers, citations, code) are
excluded from matching.

## 번역투 (korean-translationese)
```
이중피동        : (되|불려|쓰여|보여|나뉘어|모아|잊혀|읽혀|짜여|닫혀)지(다|고|는|ㄴ|며|어)
                : 되어지 | 되어진
무생물주어+주장  : (이|본|해당)\s?(논문|연구|장|절|글|표|그림|결과|분석|모형|이론|가설)[은는이가]\s?[^.]{0,40}(주장|제시|시사|강조|보여주|입증|설명|의미)(한다|하였|했)
~의 그것        : 의\s?그것(들)?
가지다 have     : [을를]\s?(가지고\s?있|가진다|가졌|가지지\s?않)
there is 있다   : (이|가)\s?있(었)?다\.?$
위치하다        : 에\s?위치(하|해)
free from       : (으로부터|로부터)\s?자유
사동 make       : 게\s?만들(었|어|ㄴ다|다)
에 대하여류      : (에\s?대(하여|한|해서|해)|에\s?있어서|의\s?경우)
을 통해         : [을를]\s?통(해|하여)
하나의          : (^|\s)하나의\s
무정물 복수들    : (변수|결과|요인|효과|기업|가격|모형|함수|정책|시장|자료|값)들[은는이가을를에]
will 미래        : ㄹ\s?것이(다|었다)
```

## 만연체·명사화 (korean-verbosity)
```
빈동사+동작명사  : (검토|분석|추정|측정|평가|비교|고려|논의|설명)[을를]\s?(수행|진행|실시)(하)
                : (증가|감소|상승|하락|개선|악화|안정)[를을]?\s?(야기|초래|유발)
이루어지다 명사화 : (이|가)\s?이루어진다
존재한다        : (이|가)\s?존재한다
문장길이        : 한 문장 어절 45+ 또는 쉼표 4+ → 분할 후보
겹말           : 미리\s?예측|다시\s?재|서로\s?상호|약\s?[0-9]+%\s?정도|남은\s?여생
```

## 어문규범 (korean-norm-lint) — 결정론적, 신뢰도 높음
```
의존명사 붙임오류: (할|한|볼|본|온|간|는)(수|것|바|지|채)(?=[\s은는이가을를])
-어지다 띄움오류 : (어|여)\s지(다|ㄴ다|고|는)
조사 겹침 오류   : \s(뿐만|밖에|만큼)\s
로써/로서       : (으?로써|으?로서)
콜론/세미콜론    : [;:：]           # 한국어 문말에서 → 마침표
강조 큰따옴표    : "[^"]{1,12}"(?=[은는이로을를])
접두사 제-      : 제\s[0-9]
관형사 붙임오류  : (각|전|매|본|동|귀)(가정|국민|회계|연구|회사|단계)
```

## 격식·시제 (korean-register)
```
경어체 종결     : (합니다|입니다|습니다|해요|네요|는데요|죠)[.\s]
구어 담화표지    : (되게|엄청|좀|사실은|아무튼|그냥|막|뭐)
추측 남발       : (것\s같다|라고\s생각된다|인\s듯하다)
미래형 남발      : ㄹ\s?것이(다|었다)
```

## 결속·호응 (korean-cohesion)
```
지시어 남용     : (이것|그것|이러한|그러한|해당)     # 문단 내 임계 초과 시
라는 사실/점    : 라는\s?(사실|점)[을를이가]
접속부사 과다    : ^(그러나|따라서|또한|그리고|하지만)  # 연속 문두 빈도
주술 거리       : 주어 뒤 서술어까지 어절 20+ → 관형절 분할
```

## 운용 규칙
- **detect → suggest → confirm** 3단계. 정규식은 confirm 단계로 넘기는 필터일 뿐.
- Stage별 독립 통과. 한 pass에 한 defect class만.
- 매칭 전에 protected span을 마스킹(수식·인용·숫자·코드).
