# 학술 접속·격식 표현 + 이중피동 목록 + 윤문 체크리스트

## 학술 논증 연결 표현 세트 (권장 어휘)
문장마다 붙이지 말 것 — 필요한 곳에만. 남용은 오히려 논리를 산만하게 한다.

| 기능 | 권장 표현 |
|---|---|
| 첨가/전개 | 또한, 아울러, 나아가, 더욱이 |
| 인과 | 따라서, 그러므로, 이에 따라, ~ㄴ 결과 |
| 대조/전환 | 그러나, 반면, 이와 달리, 한편 |
| 예시/부연 | 예컨대, 구체적으로, 즉 |
| 인용/근거 | ~에 따르면, ~을 근거로, 선행연구는 ~을 보고한다 |
| 한정/유보 | 다만, 단, ~에 한하여, 일부에서는 |

구어·비격식 → 격식:
되게/엄청 → 매우 · 좀 → 다소 · 그래서 결국 → 따라서 · 아무튼 → 요컨대 ·
~인 것 같다 → ~로 보인다/판단된다 (근거 제시 후)

## 이중피동 탐지 목록 (전부 단일 피동으로)
되어지다→되다 · 불려지다→불리다 · 쓰여지다→쓰이다 · 보여지다→보이다 ·
나뉘어지다→나뉘다 · 모아지다→모이다 · 잊혀지다→잊히다 · 읽혀지다→읽히다 ·
짜여지다→짜이다 · 닫혀지다→닫히다. `-되어지다`는 전부 `-되다`.

## 조사 호응 자주 틀림
- **로써(수단/도구)** vs **로서(자격/지위)**: 실험으로써→실험으로 · 경제학자로써→경제학자로서
- **에(무정물)** vs **에게(유정물)**: 정부에 보조금을→정부가 기업에게
- **와/과**, 병렬 항목 품사·형식 통일: "효율적이고 공평성을 높인다" → "효율성을 높이고 공평성을 개선한다"

## 문장부호 (번역본 빈발)
- 콜론 `:` / 세미콜론 `;` — 한국어 어문규범에 영어식 용법 없음 → **마침표**로.
  "…다음과 같다:" → "…다음과 같다."
- 강조는 **작은따옴표** `'…'` (큰따옴표는 직접 인용).

## 윤문 워크플로 체크리스트 (실행 순서 = top-down)

**Stage 0 준비**
- [ ] 용어집 확보 (원어–역어 1:1)
- [ ] 종결체(~한다)·시제(현재형 기본) 정책 확정
- [ ] protected span(수식·인용·숫자·코드) 스냅샷

**Stage 1 구조/논리** — 주장–근거 일치, 문단 연결
**Stage 2 문장** — 만연체 분할, 명사화→동사화, 겹말 제거
**Stage 3 번역투** — 무생물주어·we·그것·피동·have·make·숙어·에대하여·하나의·~들
**Stage 4 격식/용어** — 서술체·시제, 구어체 제거, 용어 일관성
**Stage 5 규범** — 띄어쓰기·조사·부호·맞춤법 (결정론적)
**Stage 6 재검** — 새 불일치 재검토, **원문 의미 보존 확인**, parity 재검

원칙: **detect → suggest → confirm**. 자동 치환 금지(어문규범만 예외).
한 pass에 한 defect class. 과도 교정 경계.
