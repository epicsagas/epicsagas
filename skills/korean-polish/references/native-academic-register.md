# 네이티브 한국어 학술 문체 — 번역투 vs 한국인이 쓴 글

Grounded in real Korean journal abstracts (with parallel Korean/English abstracts)
and 국립국어원 / 대학 글쓰기 guides. The tell between "translated-from-English"
and "written by a Korean scholar" is **structural/discourse**, not lexical: a paper
can have zero surface errors and still read as a translation. This pack targets that
layer. Field split matters — **economics prefers 한자어 개념어; CS absorbs 외래어**.

Native skeleton observed in real abstracts: ① speaker lowered to **본고에서는 /
본 연구에서는** (adverbial -에서는, not 본 논문**은** as an agent), ② inanimate/field
subjects dissolved into **비인칭·능동·피동** (분석 결과 …로 나타난다), ③ results/
implications closed with field idioms (**~로 나타났다 / ~을 보인다 / ~할 필요가
있다**), ④ English connectives, punctuation, plurals, pronouns, ~의 그것, and
inserted clauses stripped out.

## 축 1 — 추상·무생물·분야 주어 강등 (가장 강한 tell)
Real bilingual abstract: EN "Study revealed that…" / KO "분석 결과 …로 나타났다"
(not "본 연구는 …을 밝혀냈다"). Korean lowers the field/paper/table to an adverbial
background and states the result impersonally.

| English | 번역투 | 네이티브 |
|---|---|---|
| This paper proposes a model of… | 본 논문은 …의 모형을 제안한다 | 본고에서는 …의 모형을 제안한다 |
| This paper is organized as follows. | 본 논문은 다음과 같이 구성된다 | 이 논문의 구성은 다음과 같다 |
| The model assumes that… | 모형은 …라고 가정한다 | 이 모형에서는 …라고 가정한다 |
| Industrial economics models predict… | 산업경제학 모형들은 예측한다 | 산업조직론에 따르면 …로 예측된다 |
| Section 3 presents the results. | 3절은 결과를 제시한다 | 3절에서는 결과를 제시한다 |
| Table 2 shows that… | 표 2는 …을 보여준다 | 표 2에 따르면 …이다 / 표 2에서 보듯 … |
| Our results suggest that… | 우리의 결과는 …을 시사한다 | 분석 결과는 …을 시사한다 / …로 나타났다 |
| This study revealed that… | 본 연구는 …을 밝혀냈다 | 분석 결과 …임이 확인되었다 |
| The theory explains why… | 이 이론은 …인지 설명한다 | 이 이론으로 …인 이유를 설명할 수 있다 |

## 축 2 — 문장 길이·절 구조
좌분지 관형절 탑과 삽입절(em-dash/콤마)을 끊는다. 영어 한 문장 → 한국어 두세 문장.

| 번역투 | 네이티브 |
|---|---|
| 이 결과는, 앞서 언급했듯이, 강건하다 | 앞서 언급했듯이 이 결과는 강건하다 |
| 소비자는, 예산 제약하에서, 효용을 극대화한다 | 소비자는 예산 제약하에서 효용을 극대화한다 |
| 이 모형은 두 기간을 가지는데, 각 기간에서 …설정하고, 이는 …영향을 미친다 | 이 모형은 두 기간으로 구성된다. 각 기간에 기업은 가격을 설정하며, 그 가격은 다음 기간의 수요에 영향을 미친다 |

## 축 3 — 명사화·종결 (have/show 직역)
| 영어 / 번역투 | 네이티브 |
|---|---|
| The model has three properties. → 모형은 세 성질을 가진다 | 모형에는 세 성질이 있다 / 모형은 …성질을 지닌다 |
| a unique equilibrium → 유일한 균형을 가진다 | 유일한 균형이 존재한다 |
| results show a positive effect → 결과는 …을 보여준다 | 분석 결과 양(+)의 효과가 나타난다 |
| It is this mechanism that drives… → …을 이끄는 것은 이 메커니즘이다 | 이 메커니즘이 …을 이끈다 |
| because of the existence of frictions → 마찰의 존재 때문이다 | 마찰이 존재하기 때문이다 |
| an increase in productivity → 생산성의 증가 | 생산성 증가 (겹 '의' 제거) |

> 예외: 수학 증명·정리 맥락의 "we show that" = "…임을 보인다"는 관용형이니 유지.

## 축 4 — 담화 연결·논증 표지 (사전 1:1 금지)
| 영어 | 번역투 | 네이티브 |
|---|---|---|
| Moreover, … | 게다가 | 또한 / 아울러 |
| However, … | 하지만 | 그러나 / 반면 |
| On the other hand | 다른 한편으로는 | 반면(에) |
| Thus/Therefore | 그래서 | 따라서 / 그러므로 |
| In other words | 다른 말로 | 즉 / 다시 말해 |
| To this end | 이 끝을 위해 | 이를 위해 |
| As a result | 결과로서 | 그 결과 / 결국 |
| Given this | 이것이 주어지면 | 이에 / 이러한 점에서 |

어미(-으므로/-지만/-는데)로 논리가 드러나면 접속부사는 삭제한다.

## 축 5 — 어휘 register: 한자어(econ) vs 외래어(CS)
경제학은 한자어 개념어가 표준; 불필요한 외래어는 오히려 번역티. CS는 외래어·약어를 자연 흡수(억지 순화가 더 어색).

| 영어 | 번역티 외래어 | 경제학 정착어 |
|---|---|---|
| framework | 프레임워크 | 분석틀 / 이론틀 |
| primitive (of a model) | 프리미티브 | 기본 요소 / 원초 개념 |
| trade-off | 트레이드오프 | 상충관계 |
| channel | 채널 | 경로 |
| benchmark model | 벤치마크 모델 | 기준 모형 |
| robustness | 로버스트니스 | 강건성 |
| spillover | 스필오버 | 파급효과 |
| welfare | 웰페어 | 후생 |
| counterfactual | 카운터팩추얼 | 반사실(적 분석) |

CS 유지어(자연): 프레임워크·파이프라인·토큰·컨텍스트·에이전트·태스크. 개념어 정착역: elasticity=탄력성, depreciation=감가상각, endogenous/exogenous=내생적/외생적, identification=식별, moral hazard=도덕적 해이. 하이픈 접두·음역 어포스트로피 제거(항-암→항암, 64-비트→64비트).

## 축 6 — 주제-초점(topic-comment) 배열
구정보(은/는) 앞, 신정보(이/가) 뒤. 문말 부사구는 문두로. ~의 그것 금지.

| 번역투 | 네이티브 |
|---|---|
| 한국의 물가는 미국의 그것보다 높다 | 한국은 미국보다 물가가 높다 |
| 수요의 탄력성은 공급의 그것을 초과한다 | 수요는 공급보다 탄력성이 크다 |
| 가격은 증가한다 장기적으로 | 장기적으로 가격은 상승한다 |
| 그 효과는 크다 소규모 기업에 대해 | 소규모 기업일수록 그 효과가 크다 |

## 축 7 — 분야 관용 표현 (econ / CS)
| 영어 | 번역투 | 네이티브 관용형 |
|---|---|---|
| We estimate the model by GMM. | 우리는 GMM에 의해 추정한다 | GMM으로 모형을 추정한다 |
| controlling for firm size | 기업 규모를 위해 통제하면서 | 기업 규모를 통제한 뒤에도 |
| robust to… | …에 대해 강건하다 | …을 달리해도 결과는 강건하다 |
| statistically significant | 통계적으로 유의미하다 | 통계적으로 유의하다 |
| Assumption 1 holds. | 가정 1이 유지된다 | 가정 1이 성립한다 |
| the effect is driven by… | …에 의해 이끌어진다 | 주로 …에서 비롯된다 |
| outperforms the baseline (CS) | 베이스라인을 능가한다 | 기준 모형보다 우수한 성능을 보인다 |
| Experimental results demonstrate… (CS) | 결과들은 …을 증명한다 | 실험 결과 …임을 확인하였다 |

## 재작성 체크리스트 (순서대로)
1. 화자 표지 통일(본고에서는/이 논문에서는; 논문·표·분야를 행위 주어로 세운 문장 색출)
2. 무생물·분야 주어 강등(모형은 가정한다 → 모형에서는 가정한다; 결과는 보여준다 → 분석 결과 …로 나타난다)
3. 수동태·'~에 의해' 정리(by-수동 → 능동; 진짜 행위주만 남김)
4. have/show 직역 교체(있다/이다/지니다; 나타난다/시사한다)
5. 문장 분절(영어 1문장 → 한국어 2–3문장; 관형절 탑·삽입절 풀이)
6. ~의 그것 및 겹 '의' 제거
7. 정보 배열(구정보 앞/신정보 뒤; 문말 부사구 문두로)
8. 접속 표지 재배분·감량
9. 명사화·'것이다' 감량
10. 어휘 register 확정(econ 한자어 / CS 외래어; 프레임워크→틀 등)
11. 결과·함의 종결 관용화(~로 나타났다 / ~할 필요가 있다 / ~을 시사한다)
12. 복수 ~들·대명사·'우리' 청소
13. 문장부호 정리(콜론·세미콜론→마침표; 강조 작은따옴표; 하이픈 접두 제거)
14. 소리 내어 읽기 — 어색하면 원문 구조가 비치는 곳이니 뜻만 남겨 다시 쓴다

## 지양할 대표 번역투 20선
본 논문은~제안한다→본고에서는 · 모형/결과는~보여준다(무생물주어)→…에서는/분석 결과 · ~에 의해(불필요 by-수동)→능동 · ~을 가지고 있다→…이 있다/이다 · ~의 그것→서술절 · ~들(기계적 복수)→삭제 · 우리는~(we)→생략/비인칭 · ~하는 것이다/~라는 것이다→단정형 · ~을 위해 통제하면서→…을 통제한 뒤에도 · …에 대해 강건하다→…을 달리해도 강건하다 · 게다가/다른 한편으로는→또한/반면 · 다음과 같다:(콜론)/세미콜론/강조 큰따옴표→마침표·작은따옴표 · A, B 그리고 C→A와 B, 그리고 C · 가장 …한 것들 중 하나→…로 손꼽히는 · …의 존재 때문에→…이 존재하기 때문에 · …을 고려에 넣다→고려하다 · 프레임워크/트레이드오프→분석틀/상충관계 · 임금의 결정의 분석→임금 결정을 분석 · …인 것으로 발견되었다→…로 나타났다 · 삽입 콤마·em-dash 절→문두 부사구·별도 문장
