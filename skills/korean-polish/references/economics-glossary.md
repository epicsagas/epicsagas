# 경제학 용어집 (source term → single Korean equivalent)

**Terminology drift is the #1 defect in translated papers.** One concept = one
Korean term throughout a document. This is a *starting* glossary; extend per
document and treat the chosen column as the single source of truth. Flag any
variant spelling as a `korean-register` violation.

| English | 표준 역어 (use this) | 지양 (variants to flag) |
|---|---|---|
| elasticity | 탄력도 | 탄력성, 탄성, 신축성 |
| marginal product | 한계생산 | 한계생산물(문맥상 허용), 마지널 |
| equilibrium | 균형 | 이퀄리브리엄, 평형 |
| utility | 효용 | 유틸리티 |
| production function | 생산함수 | 생산 함수(띄어쓰기 혼용) |
| returns to scale | 규모수익 / 규모에 대한 수익 | 규모수확, 스케일 리턴 |
| increasing returns | 수익 체증 / 체증 수익 | 증가 수익 |
| depreciation | 감가상각 | 절하(문맥 다름), 디프리시에이션 |
| capital stock | 자본 스톡 | 자본재고, 자본 축적량 |
| intangible capital | 무형자본 | 무형 자산(asset과 구분) |
| endogenous / exogenous | 내생적 / 외생적 | 내부적/외부적 |
| identification | 식별 | 동정, 아이덴티피케이션 |
| simultaneity | 동시성 | 동시 발생성 |
| within estimator | within(저장소 내) 추정량 | 내부 추정량 |
| fixed effects | 고정효과 | 픽스트 이펙트 |
| robustness | 강건성 | 로버스트니스, 견고성 |
| specification | 사양 / 설정 | 스펙, 명세(문맥 구분) |
| markup | 마크업 / 가격 인상폭 | 마진(margin과 구분) |

| proxy | 대리변수 | 프록시(문맥상 허용) |

## 규칙
- 문서마다 실제 쓰인 역어를 스캔해 이 표에 없는 핵심 용어를 추가.
- 원어 병기(첫 등장 시 `역어(English)`)는 논문 관례상 유지.
- 영문 고유명사·약어(EIC, W, C, X, LP, PIM)는 protected span — 번역·변형 금지.
- 동형이의 한자어 주의: 원어와 뜻이 미묘하게 다른 한자어를 그대로 쓰지 말 것.
